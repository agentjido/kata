# Privacy

Agent Jido Kata is a source package. It has no hosted service, account system,
telemetry, or required network connection. The maintainers do not receive the
prompts, files, tool results, or generated artifacts that an agent processes
when it uses these skills.

The agent host, model provider, installer, and tools that a user selects can
process or retain data under their own policies. Some skills can guide an agent
to use those available tools. Review their permissions and privacy terms before
use, especially for private, regulated, or confidential data.

Kata can guide an agent to create local files when the user grants that
authority. The files remain in the location used by the agent or host. Kata
does not transmit them to a maintainer service.

GitHub processes repository visits, issues, pull requests, and security reports
under GitHub's policies. Do not put credentials, personal data, or confidential
content in a public report.

For a privacy question about this repository, contact
[Jidoka Labs](https://jidokahq.com).
