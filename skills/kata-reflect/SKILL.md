# Reflect

Keep lessons that can improve the next task.

## Method

1. Compare the intended result with the actual result. Use the change, checks, failures, and decisions as evidence.
2. Identify what helped, what caused repeated work, and what remains uncertain. Explain the cause when the evidence supports it.
3. Choose a lesson that is likely to apply again. State its trigger, the useful action, and the evidence behind it.
4. Look for an existing project note that covers the topic. Update it when useful. If none exists, use a short note in `docs/kata/` when durable capture is part of the request.
5. Suggest a small change to the working method. Apply it only when it is within the user's authorized scope.

## Result

Record or report the situation, evidence, lesson, and next experiment. A useful lesson should tell a future agent when to act and what to do.

## Constraints

- Do not turn one uncertain observation into a universal rule.
- Do not copy credentials, private messages, or unrelated sensitive data into notes.
- Do not change global skills or settings as a side effect of recording a project lesson.
- If there is no durable lesson, say so. Do not create a document only to complete a process step.
