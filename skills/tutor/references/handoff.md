# Work handoff

Use this format when learning produces work that another agent can perform:

```text
Outcome and purpose: <observable result and why it matters>
Inputs: <sources and prior decisions>
Includes and excludes: <work boundary>
Allowed actions: <authority>
Reserved decisions: <human decisions>
Done when: <completion conditions and evidence>
Open questions and next owner: <remaining handoff>
```

The learner must understand the brief. Return it as a ready-to-use `$jido`
request when the learner wants the method applied or verified. Tutor does not
invoke Jido or start the work. Jido can clarify, assign, execute, and verify
within the learner's authority. Do not claim independent human practice from
work that an agent completed.
