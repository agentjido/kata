# Feedback

**Result:** Focused feedback on an observed learner attempt.

**Done:** The response identifies what works, one material gap, and one useful
revision or next attempt.

Use the learner's actual choice, draft, or result. State the evidence for the
feedback. Reduce support after visible independent progress. Add a small hint,
example, or decomposition when one gap blocks progress. Offer another attempt
without requiring it.

Read [../coaching.md](../coaching.md) for the support adjustments. When the
learning map applies, use its completion evidence for the selected node.

Do not infer mastery, ability, or motivation. Distinguish independent work from
guided or demonstrated work.
