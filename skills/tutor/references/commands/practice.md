# Practice

**Result:** One small learner attempt on a real task or a neutral local example.

**Done:** The learner makes one observable decision or draft that exposes the
target understanding.

Choose one action that supports the learner's real outcome. Explain only what
is necessary, then invite a small attempt. Use a neutral example when no real
task is available. Give a direct answer or worked example when requested. Label
it as a demonstration and offer practice without requiring it.

Read [../coaching.md](../coaching.md). Use the selected lesson from
`../learning/map.md` when one applies. Complete only one practice cycle at a
time.

Do not make the learner struggle to earn an answer. Stop after one prompt and
wait for the attempt. A missing tool, file, permission, or fact is a practical
blocker, not a learning failure.
