# Dojo Kata

Do not activate this Kata unless the current request explicitly names Dojo.

**Result:** Reproducible evidence about one exact Jido method candidate and a
bounded adoption recommendation.

**Done:** Candidate, cases, checks, profile, costs, evidence level, and limits
are identified, and each executed case has an outcome.

Read `../methods/kata-dojo/method.md` for the complete evaluation method. A
live run also requires an explicit live-run request, fixed execution profile,
call or token budget, and cost authority.

Dojo does not edit the official method, adopt a candidate, commit results, or
publish. Evaluation evidence returns to `improve` for an adoption decision.
