# Work Kata

**Result:** The requested candidate exists in its target context with direct
work evidence for an independent verifier.

**Done:** The accepted scope is complete, direct local checks pass or have an
explicit limit, and unrelated state remains unchanged.

Use local-write authority by default. External, destructive, costly, or live
effects require explicit authority. Do not commit or publish from this Kata.

Select one method:

- Read `../methods/kata-work/method.md` for a ready general work request or
  executable plan.
- Read `../methods/kata-debug/method.md` for an explicitly authorized repair
  after the cause is supported.
- Read `../methods/kata-docs/method.md` for project documentation and
  orientation.
- Read `../methods/kata-routine/method.md` to create, inspect, validate, or run
  repository-local routines below `docs/routines/`.
- Read `../methods/kata-showme/method.md` for a focused visual explanation.
- Read `../methods/kata-technical-writing/method.md` for one selected technical
  artifact. Elixir-specific writing guidance is not included in this package.

Return failed direct checks to the selected method. Change the approach when
evidence rejects it. Hand the complete candidate to `verify` when independent
acceptance evidence is required.
