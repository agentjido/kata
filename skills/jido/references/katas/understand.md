# Understand Kata

**Result:** An evidence-supported current-state account, diagnosis, or Git
workbench report that lets the next consumer act without guessing.

**Done:** The blocking question is answered as far as available evidence
permits, facts and inferences are separate, and missing evidence is explicit.

Use read-only authority by default. A single non-pruning Git fetch is permitted
only when the request needs current remote comparison and active rules permit
it. Do not repair the target from this Kata.

Select one method:

- Read `../methods/kata-understand/method.md` for current condition, research,
  recall, or existing-system explanation.
- Read `../methods/kata-debug/method.md` for a reproducible software or agent
  failure. Stop after diagnosis unless the request also authorizes repair; an
  authorized repair moves to `work`.
- Read `../methods/kata-sitrep/method.md` for local and remote Git workbench
  state. Do not use it for application health or general project progress.

Return the evidence, limits, next ready Kata, and any accountable decision.
