# Lead Kata

**Result:** A useful learning result or a bounded assignment with a known
worker, authority, return condition, and integration owner.

**Done:** Teaching is tied to an observed attempt, or delegated work has a
complete brief and a checked state. A worker return alone does not complete the
larger request.

Select one method:

- Read `../methods/kata-tutor/method.md` when the user asks to learn, practise,
  or receive coaching on agent leadership.
- Read `../methods/kata-delegate/method.md` when defined work benefits from
  separate ownership, parallel work, or managed check, watch, and drive
  follow-through.

Starting a worker, sending a message, or creating a remote task requires the
matching tool and authority. Jido retains integration ownership.
