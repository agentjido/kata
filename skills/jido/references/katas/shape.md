# Shape Kata

**Result:** A supported direction, decision roadmap, bounded work brief, or
software implementation plan that makes later work executable.

**Done:** The requested shaping artifact has an accurate readiness state and
names every unresolved material decision instead of inventing it.

This Kata can inspect context and write the requested local brief or plan. It
does not implement the result, create remote tracker state, commit, or publish.

Select the first unresolved method:

- Read `../methods/kata-idea/method.md` when product intent, beneficiary,
  behavior, or success signals are unsettled.
- Read `../methods/kata-roadmap/method.md` when a clear destination has
  dependent decisions that require several review cycles.
- Read `../methods/kata-scope/method.md` when the outcome is clear but the
  boundary, exclusions, dependencies, or acceptance evidence are not.
- Read `../methods/kata-plan/method.md` when ready software work has material
  technical decisions, dependencies, migrations, or several verifiable units.

Do not force every method. A report, scope, or plan can be the complete
requested result.
