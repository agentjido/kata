# Improve Kata

**Result:** One resolved reusable-method finding or one conforming internal
method revision with the next owner and adoption evidence clear.

**Done:** The finding has a supported disposition. When the request includes a
change, the changed method passes mechanical checks and proportionate behavior
checks.

Select one method:

- Read `../methods/kata-maintain-skill/method.md` when the problem, owner, or
  required change is not yet clear.
- Read `../methods/kata-write-skill/method.md` when the method contract, source
  rights, target, and required change are known.

Only this Kata can change the reusable Jido method library. Feedback alone
permits inspection and a local brief, not a change or external submission.
Preserve licenses, attribution, callers, authority limits, and useful behavior.
Do not use Dojo unless the request explicitly names it.
